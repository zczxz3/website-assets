# Independent motion components

Twenty-five mount entries return a destroyable component instance. Include `styles.css` and keep `core.mjs` and `frame-scheduler.mjs`. Batch-two entries also require `batch-two.mjs`.

See [the API](../COMPONENT_API.md) for module-specific requirements, [batch two](../BATCH_TWO.md) for new references and [verification](../STUDY_VERIFICATION.md) for measured coverage. Original procedural artwork, generated tones and synthetic data are distinguished from the production references.
